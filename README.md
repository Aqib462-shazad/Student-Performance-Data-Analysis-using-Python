# Student Performance Data Analysis using Python

## Project Overview
This project analyzes student performance data using Python. The goal is to identify factors affecting academic performance through exploratory data analysis (EDA).

## Tools & Libraries
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- Jupyter Notebook

## Key Analysis
- Gender distribution analysis
- Parent education impact
- Marital status analysis
- Sports participation analysis
- Score comparison

## Project Outcomes
- Students with educated parents tend to perform better academically
- Sports participation shows moderate positive impact
- Parent marital status has limited impact on scores
